# design-architecture

Plugin thiết kế kiến trúc giải pháp của nhóm **design-system**: biến tài liệu BA thành bộ tài liệu kiến trúc có số liệu thật. Plugin phụ thuộc vào `design-core` và chỉ chứa template, checklist và phần "dùng với core". Hiện mới là bộ khung.

## Dùng cùng design-core

Plugin này còn là khung, chưa có phần bổ sung cho dữ liệu đầu vào hay ví dụ done-when; xem [PLAN.md](../PLAN.md) và dùng quy trình của `design-core`.

## Cài đặt

```
/plugin install design-architecture --marketplace tankhangkm12/Thanh-Tan-
```

Cần cài cả `design-core` và `design-architecture`; xem [hướng dẫn sử dụng](../core/USAGE.md).
